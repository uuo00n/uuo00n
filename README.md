## Vibecoding in Practice

I use `vibecoding` as an engineering method, not a shortcut.

**Toolchain**

- Codex, Cursor, ChatGPT, Claude
- GitHub, GitHub Actions
- Flutter/Dart toolchain, Node.js ecosystem, Docker

**Workflow**

1. Spec first: turn requirements into explicit acceptance criteria.
2. Fast prototype: use AI to draft code and alternatives quickly.
3. Human review: enforce architecture, naming, and maintainability standards.
4. Test and verify: run targeted tests, regression checks, and edge-case validation.
5. Ship safely: merge with CI checks, keep observability, and preserve rollback paths.

**Quality Gates**

- PR checklist for scope, risk, and backward compatibility.
- Required test pass before merge (unit/integration where applicable).
- Explicit logging and error-handling standards for key paths.
- Keep changes small and reversible to reduce release risk.
